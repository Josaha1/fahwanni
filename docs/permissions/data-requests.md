# Data permission requests (drafts — the app owner sends these)

Status: DRAFT — not sent. Written 2026-09-29 by Claude for the app owner to review and send.

Why: the app only uses data sources whose terms of use are published. ThaiWater (สสน.) publishes no terms
for its live API, and EGAT publishes none for its dam CCTV images, so both were removed from the app
(docs/plans/map-water-v2.md). If either agency grants permission in writing, the features can return.

---

## 1. ถึง สถาบันสารสนเทศทรัพยากรน้ำ (สสน.) — ขออนุญาตใช้ข้อมูลจาก API คลังข้อมูลน้ำแห่งชาติ (ThaiWater)

**ช่องทางติดต่อที่แนะนำ:** อีเมลติดต่อที่ประกาศบนเว็บไซต์ www.hii.or.th หรือ www.thaiwater.net (ตรวจสอบที่อยู่ล่าสุดก่อนส่ง)

**เรื่อง:** ขออนุญาตแสดงผลข้อมูลสถานการณ์น้ำจาก API คลังข้อมูลน้ำแห่งชาติ ในแอปพยากรณ์อากาศ "ฟ้าวันนี้"

เรียน ผู้อำนวยการสถาบันสารสนเทศทรัพยากรน้ำ

ข้าพเจ้า [ชื่อ-นามสกุล] ผู้พัฒนาแอปพลิเคชันเว็บ "ฟ้าวันนี้" (https://fahwanni.vercel.app) ซึ่งเป็นแอปพยากรณ์อากาศ
ภาษาไทยที่ให้บริการฟรี ไม่มีโฆษณา และไม่เก็บข้อมูลส่วนบุคคลของผู้ใช้ มีความประสงค์ขออนุญาตนำข้อมูลจาก API
สาธารณะของคลังข้อมูลน้ำแห่งชาติ (api-v3.thaiwater.net) มาแสดงผลในแอป เพื่อให้ประชาชนติดตามสถานการณ์น้ำได้สะดวกขึ้น
ได้แก่

1. ระดับน้ำและปริมาณน้ำไหลผ่านของสถานีวัดระดับน้ำ (รวมสถานีในคลอง)
2. ปริมาณน้ำในเขื่อนขนาดใหญ่ และน้ำไหลผ่านท้ายเขื่อนเจ้าพระยา
3. รายงานน้ำท่วมถนน
4. ปริมาณฝนสะสมรายสถานี และพื้นที่เสี่ยงอุทกภัย/น้ำท่วมฉับพลัน (ถ้ามี)

**รูปแบบการใช้งาน:** ระบบของแอปดึงข้อมูลจากฝั่งเซิร์ฟเวอร์ไม่เกินชั่วโมงละ 1 ครั้ง และเก็บแคชไว้ จึงไม่เพิ่มภาระให้ระบบ
ของสถาบัน แอปจะแสดงชื่อแหล่งข้อมูล "คลังข้อมูลน้ำแห่งชาติ (สสน.)" พร้อมเวลาของข้อมูลทุกครั้ง และลิงก์กลับไปยัง
www.thaiwater.net ทั้งนี้แอปไม่ได้ใช้ข้อมูลเพื่อการค้า ไม่นำข้อมูลไปจำหน่ายหรือเผยแพร่ต่อในรูปแบบชุดข้อมูล

จึงเรียนมาเพื่อโปรดพิจารณาอนุญาต หรือแจ้งเงื่อนไขการใช้งาน (เช่น การอ้างอิง ความถี่ในการเรียกข้อมูล หรือ API key)
ที่สถาบันต้องการ ข้าพเจ้ายินดีปฏิบัติตามทุกประการ

## 2. ถึง การไฟฟ้าฝ่ายผลิตแห่งประเทศไทย (กฟผ.) — ขออนุญาตแสดงภาพกล้อง CCTV เขื่อน

**ช่องทางติดต่อที่แนะนำ:** ช่องทางติดต่อบนเว็บไซต์ www.egat.co.th หรือ water.egat.co.th (ตรวจสอบก่อนส่ง)

**เรื่อง:** ขออนุญาตแสดงภาพนิ่งจากกล้อง CCTV เขื่อน ในแอปพยากรณ์อากาศ "ฟ้าวันนี้"

เรียน ผู้ว่าการการไฟฟ้าฝ่ายผลิตแห่งประเทศไทย

ข้าพเจ้า [ชื่อ-นามสกุล] ผู้พัฒนาแอป "ฟ้าวันนี้" (https://fahwanni.vercel.app) แอปพยากรณ์อากาศภาษาไทยที่ให้บริการฟรี
ไม่มีโฆษณา มีความประสงค์ขออนุญาตแสดงภาพนิ่งจากกล้อง CCTV ของเขื่อนภายใต้การดูแลของ กฟผ. (เช่น เขื่อนภูมิพล
เขื่อนสิริกิติ์ เขื่อนศรีนครินทร์ เขื่อนวชิราลงกรณ เขื่อนรัชชประภา เขื่อนบางลาง) ในหน้าข้อมูลเขื่อนของแอป
โดยจะแสดงเฉพาะภาพนิ่ง รีเฟรชไม่ถี่กว่า 1 ครั้งต่อนาทีเมื่อผู้ใช้เปิดดู ระบุแหล่งที่มา "ภาพจาก กฟผ." พร้อมเวลา และ
ลิงก์กลับไปยังเว็บไซต์ของ กฟผ. ทั้งนี้ไม่ได้ใช้เพื่อการค้า

จึงเรียนมาเพื่อโปรดพิจารณาอนุญาต หรือแจ้งเงื่อนไขการใช้งานที่ กฟผ. ต้องการ
